# tx_pool: roll back key image inserts on insert_key_images failure
author: jpk68
created_at: 2026-08-25T18:47:21Z
status: closed

Makes it so that when `insert_key_images` partially fails, already-recorded key images for the corresponding transaction ID are rolled back, preventing them from being falsely marked as spent.
