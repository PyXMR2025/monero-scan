# lmdb: look up prunable transaction data by tx ID
author: selsta
created_at: 2026-09-11T18:13:59Z
status: open

Fixes a bug in `get_blocks_from` where gaps in `txs_prunable` could cause it to return another transaction's prunable data. Seek by transaction ID instead of advancing positionally.

The bug does not affect `wallet2`, which requests blocks with `prune=true`.
