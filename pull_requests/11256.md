# wallet2: skip canonicalization when saving to the current filename
author: selsta
created_at: 2026-09-05T23:13:33Z
status: open

Avoid unnecessary canonicalization when saving to the wallet's current filename. This prevents password changes from failing on Windows symlink or junction paths when Boost can't canonicalize them.
