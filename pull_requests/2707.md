created_at: 2026-09-17T09:12:39Z

my contribution to security theatre for beta branch / "i looked at https://pnpm.io/supply-chain-security and made a PR"

builds _should fail_ 

- `minimumReleaseAge`: im not proud of this one as hijacked packages can just wait an arbitrary amount of time before revealing themselves but its _something_
- `blockExoticSubdeps`: deps of deps **must come from the npm registry** not from git URLs or raw tarballs that **skip all the other checks**
- `trustPolicy`: a stolen developer login pushes unsigned packages that where previously signed = fail "trust level has decreased compared to previous releases"
