# qml: delay daemon startup dialog
author: selsta
created_at: 2026-07-05T18:51:39Z
status: merged

Qt 6 can briefly show the daemon startup dialog before the wallet connection state is updated, even when the daemon is already running.

Start the timer without showing the dialog immediately, and only show it after the first connection check still reports disconnected.

Part of the upcoming Qt 6 migration.
