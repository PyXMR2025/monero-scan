# multisig: erase all copies of a nonce at the same time
author: UkoeHB
created_at: 2026-09-15T22:29:07Z
status: open

EDIT: #11331

An old version of this saved nonces in a separate field of the wallet cache, but [LLM review](https://github.com/xmrack/monero-review/issues/651) pointed out nonce lifetimes are tied to specific enotes via `R = a*Hp(K)`. The current solution avoids this lifetime ambiguity without making the whole thing even more complex.
