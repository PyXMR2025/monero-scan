# Document missing wallet RPC fields (transfer/sweep results, multisig flags, …)
author: johnr365
created_at: 2026-06-04T21:25:26Z
status: merged

Adds fields present in the v0.18.5.0 wallet RPC structs but absent from the docs. Notable groups:

- **transfer/sweep results** - `transfer.{weight,spent_key_images,payment_id}`, `sweep_single.amounts_by_dest`, `sweep_all/sweep_dust/transfer_split.amounts_by_dest_list`.
- **multisig** - `prepare_multisig.enable_multisig_experimental`, `restore_deterministic_wallet.enable_multisig_experimental`, `import_multisig_info.refresh_after_import`.
- **sign/verify** - `sign.{account_index,address_index,signature_type}`, `verify.{old,version,signature_type}`.
- **misc** - `{open,close}_wallet.autosave_current`, `generate_from_keys.language`, `get_languages.languages_local`, `get_version.release`, `export_outputs.{start,count}`, `parse_uri.unknown_parameters`, `rescan_blockchain.hard`, `describe_transfer.summary`.

Types come from the C++ structs; descriptions are lint-gated. Methods that previously showed `Inputs: _None_` but gained request params (e.g. `rescan_blockchain.hard`) get a proper list.
