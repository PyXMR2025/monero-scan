# fcmp_pp_rust: build with cargo --locked
author: thomasbuilds
created_at: 2026-08-26T13:08:45Z
status: merged

Every CMake build runs plain cargo build which re-resolves and rewrites Cargo.lock instead of failing when it disagrees with Cargo.toml. --locked makes that a hard error. This matters because crypto-bigint is patched from a fork by branch name so its commit is pinned only by the lock. Only the guix vendoring step was locked so far.
