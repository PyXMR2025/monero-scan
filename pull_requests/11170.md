# simplewallet: suggest hw_reconnect on refresh
author: Ap4sh
created_at: 2026-08-22T17:00:55Z
status: merged

Fixes #11126

Hardware device errors during refresh reach the generic exception handler, so the CLI currently gives no recovery path

This adds an `hw_reconnect` hint for hardware wallets while leaving known daemon and wallet errors unchanged
