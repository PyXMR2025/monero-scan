# cmake: use relative source/binary project paths
author: jeffro256
created_at: 2026-09-15T16:02:25Z
status: open

This makes using `add_subdirectory()` on our repo from other projects play nicer. In particular, the line adding GTest as a subdirectory using the absolute source directory was broken and caused configuration failures. Fuzz include directories was broken too, and the functional tests arguments passed to Python caused runtime errors.
