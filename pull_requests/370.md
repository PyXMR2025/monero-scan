# wallet-rpc: clarify get_transfers pending vs pool
author: monerostar
created_at: 2026-07-27T23:33:58Z
status: open

## Summary

Clarifies `get_transfers` flags so readers do not treat `pending` as “any unconfirmed tx.”

**From wallet RPC code** (`on_get_transfers`):
- `pending` / `failed` → `get_unconfirmed_payments_out` (**outgoing** only)
- `pool` → `get_unconfirmed_payments` (**incoming** mempool)
- `in` → confirmed incoming (includes low confirmation counts once mined)

Matches the observation in #252 / monero-project/monero#8140 discussion.

## Changes

- Input bullet wording for `in` / `out` / `pending` / `failed` / `pool`
- Output array notes (`type` + direction)
- Short comparison table + note

Closes #252
