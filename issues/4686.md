# Dead code in DaemonManager::start
author: EntropyHoover
created_at: 2026-09-01T10:31:42Z
status: open

Currently DaemonManager has a slot function stateChanged that is connected to the m_daemon's QProcess Signal 

```cpp
bool started = m_daemon->startDetached(m_monerod, arguments);

connect(m_daemon.get(), SIGNAL(stateChanged(QProcess::ProcessState)), this, SLOT(stateChanged(QProcess::ProcessState)));
```

However, the m_daemon is start detached, the m_daemon will not contain the running information about the monerod program.

Test code

```cpp
    qWarning() << "QProcess state before startDetached:" << m_daemon->state();
    bool started = m_daemon->startDetached(m_monerod, arguments);
    qWarning() << "QProcess state after startDetached:" << m_daemon->state();
```

Result
```bash
2026-09-01 10:14:36.592	W Logging to "/home/user/.bitmonero/monero-wallet-gui.log"
2026-09-01 10:14:36.603	W qrc:/pages/Transfer.qml:979: TypeError: Cannot call method 'isHwBacked' of undefined
2026-09-01 10:14:38.080	W Loaded wallet keys file, with public address: 
2026-09-01 10:14:42.240	W QProcess state before startDetached: QProcess::NotRunning
2026-09-01 10:14:42.280	W QProcess state after startDetached: QProcess::NotRunning
2026-09-01 10:14:42.281	W QProcess state after connection: QProcess::NotRunning
2026-09-01 10:14:42.384	I Monero 'Fluorine Fermi' (v0.18.5.1-release)
Forking to background...
```

The QProcess::ProcessState only captures the program state if it is normally started. 

Test code(The --detach param is also removed)
```cpp
    qWarning() << "QProcess state before start:" << m_daemon->state();
    m_daemon->start(m_monerod, arguments);
    bool started = m_daemon->waitForStarted();
    qWarning() << "QProcess state after start:" << m_daemon->state();
```

Result
```bash
2026-09-01 10:22:28.243	W Logging to "/home/user/.bitmonero/monero-wallet-gui.log"
2026-09-01 10:22:28.254	W qrc:/pages/Transfer.qml:979: TypeError: Cannot call method 'isHwBacked' of undefined
2026-09-01 10:22:31.399	W Loaded wallet keys file, with public address: 
2026-09-01 10:22:35.672	W QProcess state before start: QProcess::NotRunning
2026-09-01 10:22:35.694	W QProcess state after start: QProcess::Running
2026-09-01 10:23:07.585	W qrc:/pages/Transfer.qml:979: TypeError: Cannot call method 'isHwBacked' of undefined
```

As a result, the slot function DaemonManager::stateChanged never gets invoked
