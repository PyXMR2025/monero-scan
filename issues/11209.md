# simplewallet: quote notes in transfer exports
author: Ap4sh
created_at: 2026-08-29T22:24:34Z
status: open

`export_transfers` writes transaction notes directly into CSV rows, so commas shift later fields and quotes can produce malformed records

this quotes the note field and doubles embedded quotes before writing it, fixing item 5 from #9360 without changing the other export behavior

tests:
- built `simplewallet`, `unit_tests`, and `test_notifier` with GCC 14.2
- full `unit_tests`: 1308 passed, 2 hardware-dependent tests skipped
- exported the `wallet_9svHk1` fixture with commas, quotes, and a newline in the note, then checked every record has 14 columns and the note round-trips unchanged through a CSV reader
