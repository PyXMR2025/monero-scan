# tests: update gtest to 1.17.0
author: Ap4sh
created_at: 2026-08-06T22:27:23Z
status: closed

updates the gtest submodule from 1.15.2 to 1.17.0 as tracked in #9669

gtest 1.17 requires C++17 and CMake 3.16. Monero already uses C++17, and the supported CI environments provide CMake 3.16 or newer

tests:
- Release build with `BUILD_TESTS=ON`, `BUILD_GUI_DEPS=ON`, and `ENABLE_FUZZ_TEST=ON`
- `unit_tests` (1291 passed, 2 skipped)
- `core_tests`
- `libwallet_api_tests`
- `multisig` functional test
