# net: clear connected state after EOF [release-v0.18]
author: guoqiangliu-ocean
created_at: 2026-08-14T21:29:16Z
status: open

## Context

This backports the focused EOF handling fix from #10940 to `release-v0.18`, as requested in https://github.com/monero-project/monero/pull/10940#issuecomment-5266496961.

A remote HTTP peer can silently close an idle connection without sending a `Connection: close` header. The blocked-mode client could continue treating that half-closed socket as reusable, causing the next request to fail.

## Changes

- mark `blocked_mode_client` disconnected on every read error, including EOF;
- detect peer EOF before reusing an idle connection;
- add loopback regression coverage for EOF, disconnected state, and reconnect.

## Scope

This branch was created directly from upstream `release-v0.18` and contains only the two EOF-fix commits from #10940. The separate transaction-construction change remains in #11093.
