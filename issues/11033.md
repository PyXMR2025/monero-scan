# rpc: hide sensitive txs from restricted block templates
author: selsta
created_at: 2026-08-03T13:45:35Z
status: open

Alternating restricted and unrestricted requests, which is a config we support, will invalidate the shared template cache. If this is considered problematic, separate caches can be added for each mode.
