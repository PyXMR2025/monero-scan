#  merchants: add EIDEX to Swappers list
author: slaenov
created_at: 2026-08-17T04:00:52Z
status: open

Adds EIDEX (https://eidex.io/screener) to the Swappers section.

**What it is.** EIDEX is a non-custodial route screener for cross-chain swaps.
It queries live quotes from 33+ sources - on-chain DEX aggregators, bridges and
no-KYC instant exchangers - and ranks them by how much the user actually
receives. EIDEX never holds funds and never executes the swap: the user
completes the exchange directly with the provider they pick, on that provider's
own terms. No account is needed to use it.

**Why this is useful for Monero users.** XMR is not quoted by on-chain DEXs, so
an XMR holder has to compare instant exchangers one at a time. A single
XMR -> BTC query on EIDEX currently returns eight of them side by side -
FixedFloat, LetsExchange, Swapuz, Exolix, ChangeNow, Alfacash, StealthEX and
Godex - with a ~4% spread between the best and the worst output on the same
amount. Three of them (ChangeNow, Godex, StealthEX) are already listed on this
page; EIDEX makes the comparison between them visible before the user commits.

**Disclosures.** Quotes are indicative, not executable - final terms are set by
the provider. EIDEX charges no commission and adds no markup; providers pay a
referral reward when a user proceeds to swap. This is stated on the page itself,
it does not change the user's rate, and routes are ranked strictly by output.

To verify: open https://eidex.io/screener, pick XMR → BTC, enter an amount and
press "Build route".
