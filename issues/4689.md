# Windows: default wallet path can be OneDrive with no warning
author: friedcash
created_at: 2026-09-02T00:29:29Z
status: closed

## What happened
On Windows 10/11, OneDrive Known Folder Move redirects Documents
(and sometimes Desktop) to OneDrive. The official GUI default wallet
location follows Documents, so a new or existing wallet .keys file is
stored under a cloud-synced folder.

I only discovered this later under Settings → Info → Wallet path.
There was no warning at wallet create/open that the file would be
uploaded to Microsoft (or other cloud if Documents is redirected).

## Why it matters
The .keys file is encrypted with the wallet password, but it is still
a spend-capable file. Syncing it to a third-party cloud is surprising
for a privacy wallet and easy to miss.

This is not a consensus/protocol bug. It is a GUI default + missing
path warning.

## What I expected
- Detect OneDrive / iCloud Drive / Dropbox / Google Drive in the path
- Warn or refuse before create/open
- Prefer a non-synced default directory on Windows

## Environment
- Official Monero GUI (Fluorine Fermi / v0.18.5.x)
- Windows, wallet originally under Documents which was OneDrive
