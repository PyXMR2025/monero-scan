# docs: document socks5:// proxy syntax for monerod and wallet-rpc
author: monerostar
created_at: 2026-07-30T14:56:36Z
status: open

## Summary

Documents the current SOCKS proxy URL syntax for operators.

- monerod `--proxy` and `--tx-proxy`
- wallet-rpc `--proxy`

## Why

Issue #310 asks to add the new socks5 syntax. Public monero-docs still said SOCKS5 was "anticipated" and only showed bare `host:port`, while core `docs/proxies.md` and the daemon help string already document:

`[socks5://[user:pass@]]host:port`

## Source of truth

- https://github.com/monero-project/monero/blob/master/docs/proxies.md
- daemon `arg_proxy` help: `[socks5://[user:pass@]]<socks-ip:port>`

## Notes

- Bare `host:port` remains SOCKS4a (unchanged default).
- Mentions percent-encoding and preferring `--config-file` for credentials (same guidance as core docs).
- Links to core proxies.md for the full matrix.

Fixes #310
