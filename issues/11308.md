# net: accept SOCKS5 domain reply addresses
author: Ap4sh
created_at: 2026-09-12T05:36:40Z
status: open

`BND.ADDR` in a SOCKS5 CONNECT reply may be IPv4, a domain name, or IPv6 under RFC 1928

the client currently handles only the two IP forms and rejects valid domain-form replies with `address_type_not_supported`

read the domain length first, then consume exactly the address and port before returning the connected socket

tests:
- debug build with system GCC 14
- `unit_tests --gtest_filter='socks*.*'`
- full `unit_tests`
