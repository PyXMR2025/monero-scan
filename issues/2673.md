# Request to add P.CASH Wallet to the Mobile & Light Wallets section
author: gades
created_at: 2026-06-20T07:19:46Z
status: open

Hello Monero Team,

We would like to request the addition of P.CASH Wallet to the Mobile & Light Wallets section on getmonero.org.

P.CASH Wallet is a free and open-source, non-custodial cryptocurrency wallet available for Android. The wallet includes native Monero (XMR) support alongside other cryptocurrencies and is actively maintained by an independent development team.

Project links:

* Google Play:
    https://play.google.com/store/apps/details?id=cash.p.terminal
* F-Droid:
    https://f-droid.org/en/packages/cash.p.terminal/
* Source Code:
    https://github.com/piratecash/pcash-wallet-android

Key features:

* Open-source
* Non-custodial
* Native Monero support
* Available through F-Droid
* Active development and regular updates
* Hardware wallet support
* Cross-chain swap functionality

We believe P.CASH Wallet would be a valuable addition to the list of wallets available to the Monero community.

If any additional information is required, we would be happy to provide it.

Thank you for your consideration.

Best regards,
P.CASH Wallet Team
