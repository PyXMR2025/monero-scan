# Document missing daemon RPC fields (get_blocks.bin, send_raw_transaction, get_info, …)
author: johnr365
created_at: 2026-06-04T21:25:23Z
status: closed

Adds fields present in the v0.18.5.0 C++ structs but absent from the daemon docs. Notable groups:

- **`get_blocks.bin`** - modern request fields (`requested_info`, `no_miner_tx`, `pool_info_since`, `max_block_count`) and pool-info response fields (`daemon_time`, `pool_info_extent`, `added_pool_txs`, `remaining_added_pool_txids`, `removed_pool_txids`).
- **`send_raw_transaction`** - response failure flags (`sanity_check_failed`, `too_few_outputs`, `tx_extra_too_big`, `nonzero_unlock_time`) and the `do_sanity_checks` request flag.
- **`get_info.restricted`**, `get_version.target_height`, `hard_fork_info.version`, `get_peer_list.{public_only,include_blocked}`, `in_peers.set`, `out_peers.set`, `get_block.miner_tx_hash`, `get_block_template.{prev_block,extra_nonce}`, `get_block_header_by_hash.block_headers`, `get_outs.bin.get_txid`, `submit_block.block_id`.

Each bullet's type comes from the C++ struct; descriptions are lint-gated. Inserted by anchor after the nearest already-documented sibling.
