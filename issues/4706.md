# network: Detect and setup the proxy for whonix 
author: EntropyHoover
created_at: 2026-09-09T09:49:20Z
status: open

This PR will detect if the user is using GUI wallet on Whonix, and Qubes-Whonix. 

When the user is on Whonix, the GUI proxy setting is set to whonix_gateway_ip:9160. For ordinary whonix the gateway ip is 10.152.152.10, and for qubes-whonix the gateway ip is dynamic and need a command line read. Whonix has IsolateDestAddr enabled on 9160. This hopefully should benefit the future remote node simple mode.

When the user is on Whonix and the wallet is set to advanced mode, a default binding for daemon flag will be applied, which has "--proxy socks5://127.0.0.1:9050 --tor-stream-isolation --tx-proxy tor,socks5://127.0.0.1:9050". This will make monero gui wallet in whonix has stream isolation and tor tx broadcast by default. User can override this default by just changing the daemon flag. This pr relies on the monero pr implements --tor-stream-isolation https://github.com/monero-project/monero/pull/11249
