# components: automatically parse domain and port of pasted strings
author: jpk68
created_at: 2026-09-07T01:09:25Z
status: open

Automatically parses addresses and ports of URLs pasted into the dialog box for adding a new remote node.

For example, you could simply paste "http://node2.monerodevs.org:18089/" into the "Address" field, and it will use regex to get the port from that string, so you don't have to manually copy it over.

Disclaimer: the regexes used were found online and verified using an LLM.
