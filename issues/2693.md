# user-guides: note payment proofs do not imply spendable funds
author: monerostar
created_at: 2026-07-31T01:21:53Z
status: open

## Summary

Adds a short **Important limitation** section to the English prove-payment user guide before "Check payments".

Successful check = amount directed to that address in the tx. Not a guarantee funds are still spendable (time lock / already spent / burnt one-time address).
